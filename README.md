# GDVHG
## About
Port of Vitruvian Human from Blender CharMorph to Godot

Currently it is a tech demo, not a full-scale human generator, like MakeHuman or something else.

## Building
### Requirements
Godot Engine 4.7

### Steps to build
1. Project->Export
2. Choose your platform (e.g. Windows/Linux/Android/Web/Mac)
